# Codex 周额度悬浮窗

[English](README.md) | 简体中文

在 Windows 和 macOS 桌面查看 Codex 额度的小工具：显示本周剩余、重置时间与倒计时、最近成功更新时间、可用重置次数；Plus 账号在 Codex 提供数据时另显示 5 小时额度。

这是独立的非官方工具，与 OpenAI 无关联，也未获其背书。

## 安装

**0.1.0** 安装包内置 Node.js **24.19.0** 及其许可证。使用预编译安装包无需另装 Node 或开发工具。

| 系统 | 文件 | 安装步骤 |
| --- | --- | --- |
| macOS 13.5+，Apple Silicon | `CodexQuotaWidget-0.1.0-macos-arm64.zip` | [macOS](macos/README.zh-CN.md) |
| macOS 13.5+，Intel | `CodexQuotaWidget-0.1.0-macos-x64.zip` | [macOS](macos/README.zh-CN.md) |
| Windows x64 | `CodexQuotaWidget-0.1.0-windows-x64.exe` | [Windows](windows/README.zh-CN.md) |

请使用同一次构建提供的安装包与 `SHA256SUMS`。构建产物位于 **Actions → Build packages → 成功的运行 → Artifacts**，下载时需要登录 GitHub。仓库已公开；工作流不会发布 GitHub Release。

先安装官方 [Codex 桌面应用](https://learn.chatgpt.com/docs/app)或 [Codex CLI](https://learn.chatgpt.com/docs/codex/cli)，并用要监控的 ChatGPT 账号登录。工具需要找到 Codex CLI／App Server；若未识别桌面安装，请按官方说明安装 CLI 后运行 `codex login`。安装包不包含 Codex 程序或任何登录凭据。

macOS 应用仅有临时签名，没有 Developer ID 签名或 Apple 公证；Windows 安装程序未签名。系统可能显示安全提示，请核对来源和校验值后再决定打开。

从源码启动需安装 Node.js 24+；macOS 还需 Apple 命令行工具，详见系统指南。同一台电脑只运行一份：本机服务使用 `127.0.0.1:39224`。

## 使用

- 在极简百分比圆环与详细窗之间切换，拖动移动或缩放；两种模式各自记住位置和尺寸。
- 从 Windows 托盘或 macOS 菜单栏显示窗口、刷新、切换语言或退出；macOS 程序坞图标也显示本周剩余。
- 极简浮窗右上角的小黄点表示有新的监控网站提示，或已确认的重置次数赠送／全局额度重置公告。提示点表示有未读消息，不表示重置已完成。悬停查看类型，打开详情后清除其中显示的提示；首次使用时已有的记录不提示，已看过的消息重启后也不重复提示。不会闪烁或发声。macOS 程序坞圆环里的数字不带百分号。
- 在**语言 → 跟随系统 / English / 简体中文**中选择。跟随系统在中文系统语言下显示中文，其余显示英文。浏览器详细页与原生界面共用已保存的选择。
- 打开**可用重置 / 详情**查看可用次数，以及 Codex 提供的发放／到期时间。未提供的日期会明确说明；工具不会消耗可用重置次数，也不推测未来发放。可用重置与付费使用额度、固定额度重置倒计时分别显示。
- **我的额度恢复**记录本机成功查询之间的额度回升，与公共重置消息放在同一列表，按时间从新到旧显示恢复前后百分比和本地发现时间。24 小时后归档，仍在同一列表中查看，其中也可查看上次观测时间。没有恢复记录时不显示单独的空模块。从首次观测建立起点，仅有真实的历史查询记录时才能补回启用前的变化；重启后保留，按账号区分，每个账号保留最近 50 条。检测时间不代表准确重置时刻，也不确认恢复原因或全局送达。套餐变化时重新建立起点。

账号额度查询和缓存检查均每 **60 秒**进行。手动刷新、重新打开和电脑唤醒后及时刷新，同时发起的请求会合并。临时查询失败后按 **15、30、60 秒**重试。不可用、已到重置时间或过旧的额度显示为 `—`，旧百分比不会继续当作当前数据。

[codex-reset.com](https://codex-reset.com/) 和 [codexreset.dev](https://codexreset.dev/) 的公开公告及送达记录单独每 **10 分钟**更新。

界面底部的**自动刷新：额度每 1 分钟 · 公共信息每 10 分钟**指上述读取间隔。工具读取监控站点的结构化接口，不会搜索 X 或调用 AI；原文短语匹配较保守，可能漏掉陌生表述。站点记录可能延迟或遗漏。官方英文名称、中文译法与来源范围见[术语与公开数据来源](docs/TERMINOLOGY.zh-CN.md)。

已确认的重置次数赠送或全局额度重置，会在来源确认完成后保留 24 小时，再进入历史。已知公告会在来源故障或重启后保留。macOS 默认详情窗口按内容及屏幕可用高度调整；手动缩放后保留选择的大小。

重置动态把当前消息、个人额度恢复和归档记录合为一个列表，按时间从新到旧显示。默认显示最近 5 条，点击**再显示 5 条**逐批查看更多，点击**只看最近 5 条**可收起。已保存的历史不会删除，只有已加载且进入窗口可见区域的记录才会清除未读。工具从 codex-reset.com 读取原帖，从 codexreset.dev 读取历史证据，以保守的短语规则识别明确预告与完成声明；网站分类、条件性表述和暗示不能单独确认重置。完成声明的时间显示为**完成声明发布**，不代表你的账号准确恢复时间，原文链接继续保留。

codex-reset.com 同时标记为“信号”和重置相关的近期消息，还会以**监控网站提示**显示，附原文、发布时间以及原帖和监控网站链接。首次成功读取建立基线后，新的网站提示也会产生未读提示点；提示点表示有新消息可查看，不表示已经确认或完成重置。只有已展开详情中实际展示的记录会清除未读，尚未加载或位于窗口可见区域外的记录继续保持未读。同一提示在读过、刷新、重启或分类修正后不会重复提醒。提示不改变最新已确认重置，也不证明个人额度已恢复。工具同时检查当前信号和最近列表保留的信号，头条更换不会单独导致旧信号被丢弃。提示从原帖发布起保留 24 小时，之后在同一列表中标记为已过期；刷新或重启不会延期。网站明确停止的信号在同一列表中标记为已停止；请求失败则保留缓存、显示数据待更新，直到提示过期。“两小时内”等相对表述只展示原文，不生成预定或完成时间。来源仍可能延迟或遗漏消息。

同一类型在 48 小时内只有一条待完成预告时，可与后续完成声明合并；多条候选无法明确对应时保留各自记录。两家重复收录的原帖按链接去重。两个接口均为部分覆盖，记录缺失不会撤销已缓存公告。原帖源的待完成预告会继续显示，首次从历史库读到的久远预告保留在历史中。未注明时区的 EOD 不会被换算成具体本地时刻或日期；旧缓存中的计划信息继续可读。

镜像分类冲突时，完整原文明确说明的类型会同时修正该链接的缓存分类；后续只收到历史库的局部更新也会保留修正。

历史公告没有送达证据时显示**来源未提供送达记录**。个人账号的发放日期，不能用来确认某条公共公告已向所有账号送达。

预定时间已过但缺少公共完成记录时，界面用中性文字说明监控来源的记录状态。个人额度独立更新；本账号额度恢复不代表全局重置已对所有账号完成。

## 隐私与故障排查

本机服务通过 [Codex App Server](https://learn.chatgpt.com/docs/app-server) 的只读 `account/read` 和 `account/rateLimits/read` 获取数据，只监听本机回环地址，无需 OpenAI API Key。不会向公开重置站点发送个人额度或登录信息；设置与日志留在本机。

本地恢复记录保存在设置目录的 `quota-recovery.json`，包含额度百分比、观测时间与加盐账号指纹，不保存账号邮箱或登录凭据。保留最近使用的五个账号记录；Codex 未提供稳定账号标识时，无法建立恢复记录。

若显示不可用，请按界面提示处理，检查 `codex login status` 后点击**刷新**。系统指南列出日志位置、重新启动及卸载步骤。反馈问题时不要上传凭据、原始账号响应、未脱敏日志或个人账号截图。

Codex 更新可能改变 App Server。托管运行环境测试使用虚构数据，不代表已验证真实账号登录或实体 Intel Mac／Windows 桌面兼容性。Windows 安装程序提供可选的登录时启动，默认不勾选。本版没有系统通知或远程同步。
