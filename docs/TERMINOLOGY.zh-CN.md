# 术语与公开数据来源

**本账号额度恢复 / Account quota recoveries**是本工具对本机观测到的额度回升所用的名称，不是官方重置类型。记录展示恢复前后百分比、上次观测与本次检测的时间区间；无法据此确定恢复原因、准确时刻或其他账号的送达状态，与公共公告历史分开显示。

## 重置术语

| 官方英文名称 | 本工具中文名称 | 含义 |
| --- | --- | --- |
| Banked reset | 可用重置 / 可用重置次数 | 保存在账号中，可在到期前由用户手动使用的一次额度重置。 |
| Global reset / automatic reset | 全局额度重置 / 自动额度重置 | 直接对公告所列符合条件的账号生效，不会增加可保留的重置次数。 |
| Credits | 付费使用额度 | 单独购买的额外使用额度，与可用重置不同。 |
| Usage limits | 用量限制 | 账号适用的使用额度限制。 |
| Weekly / 5-hour usage window | 每周 / 5 小时用量周期 | 账号的常规用量周期，与活动赠送的重置分别处理。 |

英文名称及含义依据 [OpenAI 的 Banked reset 说明](https://help.openai.com/en/articles/20001498-how-banked-codex-resets-work)。中文名称是本工具按官方含义采用的译法，并非声称 OpenAI 已统一使用这些中文名称。可用重置不是现金、充值卡或 API 额度；资格、到期时间和重置范围按具体活动及账号的 Usage 页面为准。

## 自动刷新是什么意思？

- **额度每 1 分钟：**通过本机 Codex App Server 读取已登录账号的额度；可用重置次数也来自该账号的返回数据。
- **公共信息每 10 分钟：**读取下列第三方监控站点的公开公告与完成记录。这是工具检查的间隔，不是 OpenAI 发放或重置的间隔。
- 本工具不会向这些公开站点发送个人额度或登录凭据。

| 内容 | 结构化数据来源 |
| --- | --- |
| 已记录的全局额度重置 | `https://codexreset.ai/api/v1/resets.json` |
| 已确认的计划公告与历史 | `https://whenreset.app/api/v1/resets.json` |

来源说明见 [CodexReset API 文档](https://codexreset.ai/developers/)与 [WhenReset](https://whenreset.app/)。它们是独立监控站点，不是 OpenAI 官方 API。

工具不会搜索 X、抓取推文或调用 AI 解读推文。站点提供的来源链接可能指向 X 上的公告，也可能指向其他证据。只有结构化数据明确标为 `announced` 的计划才展示为已确认；暗示和条件性表述不会当作已确认公告。只有来源提供确认完成的时间，才显示已送达；计划时间已到不等于完成。

新信息要等站点收录、工具成功刷新后才能显示，无法保证无遗漏、站点判断始终准确或即时到达。接口失败、格式变化或数据过旧时会显示不可用或待更新，已知的确认公告会保留。历史记录是公开站点的记录，不代表个人账号已经收到重置。

标明“演示数据”的截图使用虚构日期与数量，仅说明界面布局，不代表真实公告或发放证据。
